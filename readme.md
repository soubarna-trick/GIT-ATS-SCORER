# ATS Resume & Job Compatibility Scoring System

## Overview
The **ATS Resume & Job Compatibility Scoring System** is a **Flask-based web application** designed to help job seekers optimize their resumes for **Applicant Tracking Systems (ATS)**. It provides **ATS-friendly resume scoring, job description compatibility analysis, and LinkedIn talent search** using **web scraping**. The platform features a **visually appealing landing page** built with **HTML, CSS, and JavaScript**.

## Features

### 1. Resume Upload & Parsing
- Supports **PDF, DOCX, and TXT** formats.
- Extracts **skills, experience, education, and keywords** for analysis.

### 2. ATS Compatibility Scoring
- Uses **AI & NLP** to evaluate resume structure and ATS-friendliness.
- Analyzes **formatting, keyword optimization, and readability**.
- Provides an **ATS score (0-100%)** with actionable suggestions.

### 3. Job Description Compatibility Score
- Users can upload a **job description** along with their resume.
- The system calculates a **match score (%)** between the resume and job description.
- Highlights **missing keywords** and offers optimization recommendations.

### 4. AI-Powered Resume & Job Description Optimization
- Provides **real-time suggestions** to enhance ATS compatibility.
- Suggests **keyword additions, better phrasing, and formatting corrections**.
- Helps align resumes with **specific job descriptions**.

### 5. LinkedIn Talent Search Using Web Scraping
- Uses **web scraping** techniques to find professionals on LinkedIn.
- Users can enter **targeted keywords** to search for relevant profiles.
- Displays **names, job titles, and profile links** for further exploration.

### 6. Beautiful & Engaging Landing Page
- Built with **HTML, CSS, and JavaScript**.
- Features a **responsive and user-friendly design**.
- Includes **call-to-action (CTA) sections, smooth animations, and a demo area**.

### 7. PDF Report Generation
- Generates a **detailed ATS & job compatibility report**.
- Provides an **improvement checklist** for better job application success.

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Flask (Python Web Framework)
- **AI/NLP**: OpenAI API / spaCy for text analysis
- **Web Scraping**: BeautifulSoup / Selenium for LinkedIn search

## Installation
### Prerequisites
- Python 3.8+
- pip
- Virtual environment (recommended)

### Setup Instructions
1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/ats-resume-scoring.git
   cd ats-resume-scoring
   ```
2. **Create a virtual environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```
3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Run the Flask application:**
   ```bash
   python app.py
   ```
5. **Access the application in your browser:**
   ```
   http://127.0.0.1:5000/
   ```

## Usage
1. **Upload your resume** in PDF, DOCX, or TXT format.
2. **Upload a job description** for compatibility analysis.
3. **View your ATS score and job match percentage.**
4. **Optimize your resume** using AI suggestions.
5. **Search LinkedIn** for professionals using web scraping.
6. **Download a PDF report** for improvements.
